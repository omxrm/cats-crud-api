# cats-crud-api
Assignment #3: CRUD API

## Installation
- Get the project
    - clone
        ```
      git clone https://github.com/csc340-uncg/f25-jpa-crud-api.git
        ```
    - OR download zip.
- Open the project in VS Code.
- This project is built to run with jdk 21.
- [Dependencies](https://github.com/omxrm/cats-crud-api/blob/main/pom.xml#L33](https://github.com/omxrm/cats-crud-api/blob/main/pom.xml#L33)) to JPA and Postgres in addition to the usual Spring Web. JPA handles the persistence, Postgresql is the database to be used.
- [`/src/main/resources/application.properties`](https://github.com/csc340-uncg/f25-jpa-crud-api/blob/6b2860c4ad01ca46b6b62852ca966bfadc8dfc6a/src/main/resources/application.properties) This file has the configuration for the PostgreSQL database to use for the API.
  - You MUST have the database up and running before running the project!
    - Login to your neon.tech account.
    - Locate your database project.
    - On the project dashboard, click on "Connect" and select Java.
    - Copy the connection string provided.
    - Paste it as a value for the property `spring.datasource.url`. No quotation marks.
- Build and run the main class. You should see a new table created in the Neon database.

2. ### [/\{catId\}](http://localhost:8080/cats/1) (GET)
Gets an individual Cat by ID.

#### Parameters
- Path Variable: `catId` <Long> – REQUIRED

#### Response – A single Cat
```
{
  "catId": 1,
  "name": "Cora",
  "description": "Cora is a gorgeous Russian Blue cat with a sleek gray coat and lively yellow-green eyes. She loves to explore, is very playful and gives excellent \"biscuits.\"",
  "breed": "Russian Blue",
  "age": 6.0
}
```

3. ### [/search](http://localhost:8080/cats/search?q=lu) (GET)
Gets a list of cats whose **name** contains the given substring (case-insensitive).

#### Parameters
- query parameter: `q` <String> – REQUIRED

#### Response – A JSON array of Cat objects.
```
[
  {
    "catId": 10,
    "name": "Luna",
    "description": "An energetic American Curl who zooms around the house and purrs loudly.",
    "breed": "American Curl",
    "age": 3.0
  }
]
```

4. ### [/category/\{breed\}](http://localhost:8080/cats/category/Siamese) (GET)
Gets a list of cats for a named breed (category).

#### Parameters
- path variable: `breed` <String> – REQUIRED

#### Response – A JSON array of Cat objects.
```
[
  {
    "catId": 2,
    "name": "Mocha",
    "description": "Mocha is a curious Siamese with bright blue eyes.",
    "breed": "Siamese",
    "age": 5.0
  }
]
```

5. ### [/](http://localhost:8080/cats) (POST)
Create a new Cat.

#### Request Body
A cat object. The `catId` is autogenerated and **should not** be included.
```
{
  "name": "Example Cat",
  "description": "Short description here.",
  "breed": "Example Breed",
  "age": 2.0
}
```

#### Response – The newly created Cat.
```
{
  "catId": 11,
  "name": "Example Cat",
  "description": "Short description here.",
  "breed": "Example Breed",
  "age": 2.0
}
```

6. ### [/\{catId\}](http://localhost:8080/cats/11) (PUT)
Update an existing Cat.

#### Parameters
- Path Variable: `catId` <Long> – REQUIRED

#### Request Body
A cat object with the updates (no need to include `catId` in the body).
```
{
  "name": "Example Cat (Updated)",
  "description": "Updated description.",
  "breed": "Example Breed",
  "age": 3.0
}
```

#### Response – The updated Cat.
```
{
  "catId": 11,
  "name": "Example Cat (Updated)",
  "description": "Updated description.",
  "breed": "Example Breed",
  "age": 3.0
}
```
